# azul-rossini-profile

A personal profile website built with [Astro](https://astro.build).

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js installed (v18.14.1 or higher). You can download it from [nodejs.org](https://nodejs.org/).

### Installation

1. Install dependencies:
```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The site will be available at `http://localhost:4321`

### Build

Build the site for production:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

## 📁 Project Structure

```
/

├── src/

│   └── env.d.ts     # TypeScript environment definitions

```
